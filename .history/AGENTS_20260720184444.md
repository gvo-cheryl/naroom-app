# naroom-app 작업 규칙

- 프로젝트는 Expo SDK 57, React Native 0.86, React 19, TypeScript, Expo Router 기반이다.
- 라우팅 루트는 src/app이며, 신규 화면과 라우트는 이 구조를 따른다.
- 패키지 설치는 Expo 호환성을 위해 pnpm exec expo install <package>를 우선 사용한다.
- 로컬 실행은 pnpm start, iOS 실행은 pnpm ios, 정적 검증은 pnpm lint, 진단은 pnpm dlx expo-doctor다.
- 코드 변경 후 관련 검증을 실행하고 결과를 보고한다.
- .env.local, 키스토어, 인증서, 서비스 계정 JSON, 토큰·API 키는 읽기·수정·출력하지 않는다.
- EXPO_PUBLIC_ 환경변수는 앱에 노출될 수 있으므로 비밀값을 넣지 않는다.
- .env.example에는 변수명과 안전한 예시값만 유지한다.
- node_modules, .expo, dist, ios, android은 명시적 요청 없이 수정하거나 생성하지 않는다.
- 기존 코드 스타일과 Expo Router 구조를 따르며, 작업 범위를 벗어나는 변경은 먼저 설명한다.
